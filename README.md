# mboa
Projet fil rouge de la matière Application web dynamique intéractives.
(Une petite boutique en ligne de produits locaux camerounais : poivre de Penja, café de l’Ouest, miel d’Oku, cacao, huile de palme, pagnes… À chaque chapitre, vous ajoutez une fonctionnalité : catalogue affiché dynamiquement, panier, formulaire de commande avec paiement Mobile Money simulé, conversion en TypeScript, composants interactifs puis chargement des produits par AJAX. À la fin du module, vous disposerez d’un véritable projet à présenter dans votre portfolio.)
